# 🚀 Janus Prop AI - Real Estate AI Platform

A comprehensive real estate AI platform with advanced property analysis, market intelligence, and automated agent workflows.

## 🏗️ Architecture Overview

- **Backend**: FastAPI-based Python server with AI agent system
- **Frontend**: React/TypeScript with Vite and shadcn/ui components  
- **Database**: Supabase (PostgreSQL) with comprehensive schema
- **Real-time**: WebSocket support with Redis for caching/pub-sub
- **AI Integration**: Google Gemini AI, ATTOM Real Estate Data APIs

## 🤖 AI Agent System

The platform features 5 specialized AI agents:

1. **Eden** - AI Insights and Property Analysis
2. **Orion** - Google Gemini AI Integration  
3. **Atelius** - ATTOM Real Estate Data
4. **Nova** - Market Intelligence and Trends
5. **Zenith** - Lead Qualification and Management

## 🚀 Quick Start

### Option 1: Automated Setup (Recommended)

```bash
# Clone the repository
git clone <your-repo-url>
cd janus-prop-ai

# Run the automated setup and start script
python run_project.py
```

This script will:
- Check system requirements (Python 3.8+, Node.js 18+)
- Install all dependencies automatically
- Validate configuration
- Start both backend and frontend services
